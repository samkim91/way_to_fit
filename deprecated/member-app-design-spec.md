## 1. 서비스 개요

### 1.1 서비스 정보

| 항목 | 내용 |
|---|---|
| 서비스명 | Way to Fit |
| 앱 타입 | CrossFit 박스 회원용 모바일 앱 |
| 플랫폼 | iOS / Android (Flutter) |
| 기존 관리자 웹 | 코치/헤드코치/어드민 전용 (별도 운영) |

### 1.2 회원 앱의 역할

관리자 웹(코치 전용)에서 설정한 WOD·수업·회원권을 **회원이 확인하고 기록을 제출**하는 앱이다.

- 공개된 WOD 확인 (draft/scheduled 상태의 WOD는 노출 안 됨)
- 개인·팀 WOD 기록 입력 및 조회 (개인전·팀전 모두 회원이 직접 입력)
- 리더보드 확인 (동료와 비교)
- 수업 시간표 확인 (조회 전용; 예약 기능은 추후 추가 예정)
- 내 회원권 상태 확인 / 일시정지 신청
- 개인 퍼포먼스 추적 (벤치마크 WOD 이력, 1RM 기록)
- WOD 공개 알림 수신 (FCM 푸시 알림)

### 1.3 사용자 권한

앱을 사용하는 회원의 `role`은 `MEMBER` 또는 `JUDGE`이다. (Coach 이상은 관리자 웹 사용)

| 상태 | 앱 접근 가능 여부 |
|---|---|
| ACTIVE | 전체 기능 사용 |
| HOLD | 읽기 전용 (기록 입력 불가) |
| PENDING | 가입 대기 화면만 표시 |
| EXPIRED | 만료 안내 + 재등록 유도 |
| SUSPENDED | 정지 안내 화면 |

## 2. 기술 스택 & 디자인 라이브러리

### 2.1 Flutter 디자인 라이브러리 권장

**Material Design 3 (Flutter 기본 내장)** + 가벼운 커스텀 테마를 권장한다.

별도 서드파티 UI 패키지 없이 Flutter의 Material 3을 기반으로 커스텀 `ThemeData`를 구성하면 유지보수 부담이 최소화된다.

보조적으로 아래 패키지를 사용한다:

| 패키지 | 용도 |
|---|---|
| `flutter_riverpod` 또는 `bloc` | 상태 관리 |
| `go_router` | 네비게이션 |
| `dio` | HTTP 클라이언트 |
| `table_calendar` | 달력 위젯 |
| `fl_chart` | 퍼포먼스 차트 (1RM 추이 등) |
| `cached_network_image` | 이미지 캐싱 |
| `firebase_messaging` | FCM 푸시 알림 (WOD 공개, PR 달성, 회원권 만료 등) |
| `flutter_local_notifications` | 포그라운드 상태 로컬 알림 표시 (FCM 수신 시 병행 사용) |

### 2.2 최소 지원 버전

- iOS 16+
- Android API 26+

## 3. 디자인 시스템

### 3.1 테마 방향성

CrossFit은 강도 높은 운동으로, **다크 모드 우선** 디자인을 채택한다. 라이트 모드도 지원하되 다크 모드가 기본값이다.

**키워드**: 강인함, 집중, 에너지, 클린

### 3.2 컬러 팔레트

#### Dark Theme (기본)

| 역할 | 색상 | Hex |
|---|---|---|
| Background | 깊은 어두운 배경 | `#0D0D0D` |
| Surface | 카드 배경 | `#1A1A1A` |
| Surface Variant | 입력 필드 배경 | `#242424` |
| Primary (Accent) | 강조색 — 에너지 오렌지 | `#FF6B2B` |
| Primary Container | 강조색 배경 | `#3D1A0A` |
| On Primary | 강조색 위 텍스트 | `#FFFFFF` |
| Secondary | 보조 강조 — 라이트 그레이 | `#9E9E9E` |
| Success | PR 달성, 완수 표시 | `#4CAF50` |
| Warning | 예약 공개 대기 상태 | `#FFC107` |
| Error | 오류, DNF, 만료 | `#F44336` |

| On Surface | 카드 내 텍스트 | `#E0E0E0` |

#### Light Theme

| 역할 | 색상 | Hex |
|---|---|---|

## 4. 앱 구조 & 네비게이션

### 4.1 전체 화면 흐름

```
앱 시작
  └─ 스플래시
       ├─ 로그인 필요 → 로그인 화면 (Google OAuth)
       └─ 로그인됨
            ├─ PENDING → 가입 대기 화면
            ├─ EXPIRED / SUSPENDED → 상태 안내 화면
            └─ ACTIVE / HOLD → 메인 앱 (Bottom Navigation)
```

### 4.2 Bottom Navigation Bar (4탭 + FAB)

```
        ⊕  ← FAB (기록 빠른 입력, contextual)
[홈]  [WOD]  [기록]  [마이페이지]
 🏠    🏋      📊        👤
```

| 탭 | 아이콘 | 주요 콘텐츠 |
|---|---|---|
| 홈 | `home` | 오늘의 WOD, 수업 요약, 미션 진행 카드, 최근 기록 |
| WOD | `fitness_center` | 캘린더 + WOD 상세 + 리더보드 |
| 기록 | `bar_chart` | 내 전체 기록 히스토리, 벤치마크, 1RM |
| 마이페이지 | `person` | 프로필, 회원권, 미션 & 뱃지, 설정 |

**FAB 동작:**
- WOD 탭 또는 홈 탭에서 공개된 WOD가 있을 때만 표시 (contextual)
- 탭 시 → 오늘 기록 없는 WOD 목록 BottomSheet → WOD 선택 → 기록 입력
- 수업, 마이페이지 탭에서는 FAB 미표시

**통합 결정:**
- 수업 정보 → 홈 탭 "오늘의 수업" 섹션 + 마이페이지 내 "수업 시간표" 메뉴로 접근
- 미션 → 홈 탭 "이번 주 미션" 카드 + 마이페이지 내 "미션 & 뱃지" 메뉴로 접근

### 4.3 화면 계층 구조

```
Bottom Navigation (4탭)           FAB
│                                  │
├── 홈 탭                          ├── RecordQuickSheet   # 오늘 WOD 선택
│   ├── HomeScreen                 │     └── RecordSubmitSheet  # 기록 입력
│   └── ClassScheduleScreen  ◀──── 홈 "수업 전체 보기" 진입
│
├── WOD 탭
│   ├── WodCalendarScreen          # 월간 캘린더
│   ├── WodDetailScreen            # WOD 상세 (리더보드 탭 포함)
│   │   └── RecordSubmitSheet      # 기록 입력 BottomSheet
│   └── ShareCardScreen            # 기록 공유 카드 (WOD 상세에서 진입)
│
├── 기록 탭
│   ├── MyRecordsScreen            # 내 기록 타임라인
│   │   └── ShareCardScreen        # 기록 공유 카드 (기록 항목에서 진입)
│   ├── BenchmarkScreen            # Named WOD 벤치마크 이력
│   └── OneRepMaxScreen            # 1RM 기록 & 추이
│
└── 마이페이지 탭
    ├── MyPageScreen               # 프로필 + 회원권 + 메뉴 목록
    ├── MembershipDetailScreen     # 회원권 상세
    ├── HoldRequestScreen          # 일시정지 신청
    ├── MissionScreen              # 미션 & 뱃지 (마이페이지 메뉴 진입)
    │   └── MissionListScreen      # 전체 미션 목록 (카테고리 필터)
    ├── ClassScheduleScreen        # 수업 시간표 (마이페이지 메뉴 진입)
    └── SettingsScreen             # 알림 설정, 다크/라이트 모드
```

> `ShareCardScreen`은 WOD 탭과 기록 탭 두 곳에서 진입 가능하다. go_router의 동일 라우트를 재사용한다.

### 5.2 홈 탭

**목적**: 오늘 할 것(WOD·수업), 내가 한 것(최근 기록), 달성하고 있는 것(미션) — 세 가지를 한 화면에서 파악

홈 탭은 수업·미션 전용 탭을 대체하는 **정보 허브** 역할을 한다.

**상태별 WOD 카드 변형:**
- WOD 없는 날: "오늘 등록된 WOD가 없습니다."
- HOLD 상태: WOD 조회·수업·미션 카드 표시, 기록 입력 버튼만 비활성화 + FAB 미표시

**FAB 동작 상세:**
- 오늘 기록이 없는 WOD가 1개 이상 있을 때만 표시
- 탭 시 → 미기록 WOD 목록 BottomSheet (WOD 이름 + 타입 표시)
- WOD 선택 → 기록 입력 BottomSheet로 바로 연결
- 오늘 WOD 전부 기록 완료 시 → FAB 숨김 또는 `✓` 완료 아이콘으로 변경

**수업 시간표 화면 진입:**

### 5.7 알림

#### FCM 연동 개요

- **패키지**: `firebase_messaging` (백그라운드/포그라운드 모두 처리)
- **포그라운드 알림**: `flutter_local_notifications`로 In-App 배너 표시
- **딥링크**: 알림 탭 시 해당 화면으로 바로 이동 (`go_router` 딥링크 연동)
- **FCM 토큰**: 로그인 완료 후 서버에 등록 (`PATCH /api/v1/members/me/fcm-token`)
- **토큰 갱신**: `onTokenRefresh` 리스너로 자동 재등록

#### 알림 수신 시나리오

| 트리거 | 알림 내용 | 딥링크 목적지 |
|---|---|---|
| WOD 공개 (박스 스케줄러 발송) | "오늘 WOD가 공개되었습니다! 확인해보세요" | WOD 상세 화면 |
| PR 달성 (기록 저장 직후) | "🏆 새 PR! Fran 8:30 — 이전 기록 9:15" | 해당 WOD 리더보드 |

## 6. 미션 & 성취 시스템

## 7. 기록 공유 카드

### 7.1 개요

WOD 기록을 **투명 배경 PNG 이미지 카드**로 내보내어 인스타그램 스토리/피드, 카카오스토리 등 SNS에 올릴 수 있도록 한다. Strava, Nike Run Club, Garmin 등의 공유 카드와 동일한 UX.

**기술 구현 방식**: 서버 호출 없이 Flutter의 `RepaintBoundary` + `RenderRepaintBoundary.toImage()`로 위젯을 PNG 렌더링 후 공유. 완전 클라이언트 사이드 처리.

### 7.2 카드 종류

| 종류 | 비율 | 주 사용처 |
|---|---|---|
| 스토리 카드 | 9:16 (1080×1920) | 인스타그램/카카오 스토리 |
| 정사각형 카드 | 1:1 (1080×1080) | 인스타그램 피드 |

### 7.3 카드 디자인 명세

#### 레이어 구조 (아래에서 위)

```
Layer 1 (배경): 완전 투명 (alpha = 0) — PNG 내보내기 기준
Layer 2 (배경 장식): 추상화된 크로스핏 심볼 실루엣 (반투명, 30% opacity)
Layer 3 (콘텐츠): WOD 이름 + 기록 + 메타정보
Layer 4 (브랜딩): Way to Fit 로고 (우하단, 소형)
```

> **앱 내 미리보기 시**에는 Layer 1이 다크/라이트 배경으로 표시되고, 실제 내보내기(PNG)에서는 투명 처리.
> 사용자가 인스타 사진 위에 올리면 사진이 배경이 되는 방식.

#### 추상화 심볼 가이드

운동/크로스핏을 연상시키는 **미니멀 실루엣** 1개. 카드 우측 하단 또는 전체 배경에 크게 배치.

권장 심볼 후보 (디자이너 선택):
- 바벨 실루엣 (수평선 + 양끝 원판)
- 덤벨 또는 케틀벨 실루엣
- 사람이 바벨을 들어올리는 추상 실루엣 (클린 or 스내치 자세)
- 불꽃 형태의 추상 도형 (에너지 표현)

심볼 색상: Primary 오렌지 (`#FF6B2B`) 계열, 30% opacity.

- `[공유하기]`: Flutter `share_plus` 패키지로 시스템 공유 시트 → 인스타그램, 카카오톡 등으로 직접 전달

**추가 패키지:**
```
share_plus       — 시스템 공유 시트
image_gallery_saver 또는 gal  — 갤러리 저장
```

## 8. 공통 컴포넌트

### 6.1 WOD 타입 배지

```dart
// 표시 예시
WodTypeBadge(type: WodType.forTime)    // "For Time" — 파랑 계열
WodTypeBadge(type: WodType.amrap)      // "AMRAP" — 보라 계열
WodTypeBadge(type: WodType.emom)       // "EMOM" — 초록 계열
WodTypeBadge(type: WodType.maxWeight)  // "Max Weight" — 오렌지 계열
WodTypeBadge(type: WodType.custom)     // "Custom" — 회색 계열
```

각 WOD 타입은 색상과 짧은 아이콘으로 구분한다.

### 6.2 스케일 그룹 칩

```
[Rx'd ●]  [Scaled]  [BG]
```

선택된 그룹은 Primary 색상으로 채워진 ChipButton, 미선택은 아웃라인 ChipButton.

### 6.3 기록 결과 표시

| WOD 타입 | 결과 표시 예시 |
|---|---|
| For Time | `8:30` 또는 `DNF` |
| AMRAP | `8라운드 + 12reps` |
| EMOM | `143 reps` 또는 `143/150 reps ⚠️` |
| Max Weight | `115kg` |
| Custom | 입력한 텍스트 |

### 6.4 리더보드 행 컴포넌트

```
[순위] [프로필] [이름 (성별)] [그룹 배지] [기록] [PR 배지]
  1    [img]   홍길동 (남)    Rx'd        8:00    🏆
  나>  [img]   나 (나)        Rx'd        8:30    🏆 PR ←오렌지 하이라이트
  3    [img]   김철수 (남)    Rx'd        9:15
```

### 6.5 빈 상태 컴포넌트 (Empty State)

- "오늘 등록된 WOD가 없습니다" — WOD 캘린더
- "아직 기록이 없습니다. 첫 기록을 남겨보세요!" — 기록 탭
- 일러스트 + 안내 텍스트 + 행동 유도 버튼 조합

## 9. 인터랙션 패턴

### 7.1 기록 입력 플로우 (핵심 사용자 여정)

```
홈 또는 WOD 탭에서 WOD 카드
  → [기록 입력] 버튼 탭
  → 스케일 그룹 선택
  → 기록 입력 (WOD 타입에 맞는 UI)
  → [저장] 탭
  → PR이면: Confetti 애니메이션 + "🎉 새 PR!" 모달
  → 아니면: Snackbar "저장되었습니다"
  → WOD 상세 화면으로 리다이렉트 (리더보드 탭)
```

### 7.2 제스처

| 제스처 | 동작 |
|---|---|
| WOD 캘린더 좌우 스와이프 | 월 이동 |
| 수업 시간표 좌우 스와이프 | 주 이동 |
| 리더보드 팀 행 탭 | 팀원 목록 인라인 펼침 |
| 기록 카드 길게 탭 | 기록 수정/삭제 옵션 ContextMenu |
| Pull-to-Refresh | 데이터 새로고침 (전체 탭 공통) |

### 7.3 로딩 상태

- 초기 로딩: Shimmer Skeleton (카드 형태 유지)
- 데이터 갱신: 기존 데이터 유지 + 상단 LinearProgressIndicator
- 기록 저장: 버튼 로딩 스피너 + 비활성화

### 7.4 오프라인 & 에러 처리

- 네트워크 없음: 상단 배너 "인터넷 연결을 확인해주세요" + 캐시 데이터 표시
- API 에러: Snackbar (일반) 또는 전체 화면 에러 UI (초기 로딩 실패)
- 401 Unauthorized: 자동 토큰 갱신 시도 → 실패 시 로그인 화면으로

## 10. API 연동 포인트 요약

회원 앱은 아래 API 경로를 사용한다. (인증: `Authorization: Bearer {accessToken}` + `X-Box-Id` 헤더)

### 인증

| 화면 | 구현 상태 | Method | Path |
|---|---|---|---|
| 토큰 갱신 | ✅ 구현됨 | POST | `/api/auth/reissue` |
| 로그아웃 | ✅ 구현됨 | POST | `/api/auth/logout` |

### 박스 & 회원권

| 화면 | 구현 상태 | Method | Path |
|---|---|---|---|
| 박스 가입 신청 | ✅ 구현됨 | POST | `/api/v1/boxes/{boxId}/join` |
| 내 회원권 상태 | ✅ 구현됨 | GET | `/api/v1/members/me/membership` |
| 일시정지 신청 | ✅ 구현됨 | POST | `/api/v1/members/me/holds` |
| FCM 토큰 등록/갱신 | 🔧 개발 필요 | PATCH | `/api/v1/members/me/fcm-token` |

### WOD (회원용)

> 현재 백엔드에 구현된 WOD API는 `/api/v1/admin/...` 경로(코치 전용)이다.
> 회원 앱용 API는 `/api/v1/boxes/{boxId}/...` 경로로 별도 구현 필요.
> **회원은 본인 기록만 입력/수정/삭제 가능** (타인 기록 입력 불가, 코치와 다름).

| 화면 | 구현 상태 | Method | 예상 Path |
|---|---|---|---|
| WOD 목록 (날짜 범위) | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/wods?from=&to=` |
| WOD 상세 | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/wods/{wodId}` |
| 리더보드 | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/wods/{wodId}/leaderboard` |
| 개인 기록 입력 | 🔧 개발 필요 | POST | `/api/v1/boxes/{boxId}/wods/{wodId}/records` |
| 개인 기록 수정 | 🔧 개발 필요 | PATCH | `/api/v1/boxes/{boxId}/wods/{wodId}/records/{recordId}` |
| 개인 기록 삭제 | 🔧 개발 필요 | DELETE | `/api/v1/boxes/{boxId}/wods/{wodId}/records/{recordId}` |
| 팀 기록 입력 | 🔧 개발 필요 | POST | `/api/v1/boxes/{boxId}/wods/{wodId}/teams` |
| 팀 기록 수정 | 🔧 개발 필요 | PATCH | `/api/v1/boxes/{boxId}/wods/{wodId}/teams/{teamId}` |
| 팀 기록 삭제 | 🔧 개발 필요 | DELETE | `/api/v1/boxes/{boxId}/wods/{wodId}/teams/{teamId}` |
| 내 전체 기록 조회 | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/members/me/records` |
| 내 벤치마크 이력 | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/members/me/benchmark` |
| 1RM 기록 조회 | 🔧 개발 필요 | GET | `/api/v1/boxes/{boxId}/members/me/1rm` |

> **팀 기록 권한 제약**: 회원은 본인이 포함된 팀만 수정/삭제 가능.
> 동일 WOD 내 타 팀 중복 소속은 서버에서 409 반환.
