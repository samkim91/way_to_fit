## 1. 서비스 개요

CrossFit 대회를 운영하는 세 역할을 위한 플랫폼이다.

| 역할 | 플랫폼 | 설명 |
|---|---|---|
| **Organizer (주최자)** | 웹 어드민 (기존 React 앱에 탭 추가) | 대회 생성, 신청 승인, 기록 판독, 리더보드 프로젝션 |
| **Participant (참가자)** | Flutter 앱 | 참가 신청, 기록 제출, 순위 확인 |
| **Spectator (관중)** | Flutter 앱 | 리더보드 조회, 선수 프로필 조회 (로그인 불필요) |

### 핵심 플로우 요약

```
주최자
  대회 생성 → Stage(예선/본선) 구성 → Event 구성
  → 참가 신청 승인 (계좌이체 확인 후 수동)
  → 기록 판독 (YouTube 영상 검토 → APPROVED / ADJUSTED / REJECTED)
  → 리더보드 실시간 프로젝션 (현장 스크린 투사용)

참가자
  대회 목록 → 신청 (개인 or 팀)
  → 이벤트별 기록 제출 (기록값 + YouTube URL)
  → 리더보드 확인

관중
  대회 목록 → 실시간 리더보드 → 선수 프로필
```

## 2. 디자인 시스템

### 2.1 웹 어드민 — 기존 테마 유지

기존 관리자 웹(박스 관리 기능)의 디자인 시스템을 그대로 따른다.

| 역할 | 값 |
|---|---|
| Background | `#F8F9FA` |
| Card | `#FFFFFF` |
| **Primary** | `#2563EB` (파란색) |
| Muted | `#F1F5F9` |
| Border | `#E2E8F0` |
| Destructive | `#E53E3E` |
| Foreground | `#1A202C` |
| Muted Foreground | `#718096` |
| Font | Geist Variable |
| Border Radius | 0.625rem 기반 |

다크 모드 지원: 기존 앱과 동일 (카드 `#2D3748`, 배경 `#1A202C`).

**UI 컴포넌트 라이브러리**: shadcn/ui (기존 코드베이스에 이미 설치됨)
- Card, Badge, Table, Dialog, Tabs, Select, Button, Input, Checkbox, Sheet 등 기존 컴포넌트 재사용

#### 상태 배지 색상 (Competition 전용)

| 상태 | 색상 | 용도 |
|---|---|---|
| `DRAFT` | 회색 (`secondary`) | 대회 초안, 미공개 |
| `PUBLISHED` | 회색 (`secondary`) | 정보 공개 (신청 전) |
| `REGISTRATION_OPEN` | 파란색 (`primary`) | 참가 신청 가능 |
| `IN_PROGRESS` | 오렌지 (`#F97316`) | 진행 중 |
| `COMPLETED` | 초록 (`#22C55E`) | 종료 |
| `REGISTRATION_CLOSED` | 빨간 (`destructive`) | 신청 마감 |
| `PENDING` | 노란색 (`#EAB308`) | 결제 대기 |
| `CONFIRMED` | 초록 | 결제 확인 |
| `SUBMITTED` | 회색 | 기록 제출됨 |
| `UNDER_REVIEW` | 파란색 | 검토 중 |
| `APPROVED` | 초록 | 승인 |
| `ADJUSTED` | 오렌지 | 조정됨 |
| `REJECTED` | 빨간색 | 거절 |

### 2.2 Flutter 앱 — 기존 앱 테마 + Competition 확장

기존 회원 앱 테마(다크 모드 우선, Primary `#FF6B2B` 에너지 오렌지)를 따른다.  
Competition 섹션은 기존 탭과 구분되는 **Trophy / 대회** 아이콘(`emoji_events` 또는 `sports_score`)을 사용한다.

#### Competition 전용 추가 색상

| 용도 | 색상 |
|---|---|
| 1위 금메달 | `#FFD700` |
| 2위 은메달 | `#C0C0C0` |
| 3위 동메달 | `#CD7F32` |
| CONFIRMED 뱃지 | `#4CAF50` (기존 Success) |
| PENDING 뱃지 | `#FFC107` (기존 Warning) |
| 팀전 표시 | `#3B82F6` (블루) |
| 개인전 표시 | `#FF6B2B` (Primary 오렌지) |

**연결 상태 표시**:

**아이콘:**
- `★` 타이브레이커로 상위 배정된 동점자
- `⚑` 주최자 수동 순위 override 적용됨
- `—` 아직 기록 없음

## 4. Flutter 앱 — 참가자 / 관중 화면

### 4.1 앱 구조 & 네비게이션

기존 4탭 네비게이션에 "대회" 탭을 추가하여 5탭으로 확장한다.

```
[ 홈 ]  [ WOD ]  [ 대회 ]  [ 기록 ]  [ 마이페이지 ]
  🏠      🏋      🏆          📊           👤
```

**대회 탭 아이콘**: `emoji_events` (Trophy) 또는 `sports_score`

> 관중(Spectator, 비로그인 상태)은 대회 탭과 선수 프로필만 접근 가능하다.  
> 신청 및 기록 제출은 로그인 필요.

### 4.2 화면 계층 구조

```
대회 탭
  ├── CompetitionListScreen          # 대회 목록 (공개, 비로그인 가능)
  └── CompetitionDetailScreen        # 대회 상세
        ├── RegistrationScreen       # 참가 신청 (로그인 필요)
        │    ├── IndividualRegScreen # 개인 신청
        │    └── TeamRegScreen       # 팀 신청
        │         └── EventLineupScreen # 이벤트별 출전 멤버 설정
        ├── ScoreSubmitScreen        # 기록 제출 (로그인 + CONFIRMED 필요)
        └── LeaderboardScreen        # 리더보드 (공개)

프로필 탭 (마이페이지 내 또는 독립 라우트)
  ├── MyAthleteProfileScreen         # 내 선수 프로필 편집
  └── AthleteProfileScreen           # 타인 선수 프로필 조회 (공개)
```

## 5. 공통 컴포넌트

### 5.1 웹 어드민 — Competition 전용 컴포넌트

#### 대회 상태 배지 (CompetitionStatusBadge)

기존 `Badge` 컴포넌트 위에 색상 매핑:
```
DRAFT         → variant="secondary"  (회색)
PUBLISHED     → variant="secondary"  (회색)
REGISTRATION_OPEN → variant="default"    (파랑)
REGISTRATION_CLOSED → variant="destructive"(빨강)
IN_PROGRESS   → 커스텀 오렌지 bg
COMPLETED     → 커스텀 초록 bg
```

#### 기록 상태 배지 (ScoreStatusBadge)

```
SUBMITTED     → 회색 아웃라인
UNDER_REVIEW  → 파랑 아웃라인
APPROVED      → 초록 채움
ADJUSTED      → 오렌지 채움 (⚑ 아이콘 포함)
REJECTED      → 빨강 아웃라인
```

#### 순위 표시 (RankCell)

```
1위  → 금색 Bold (#FFD700)
2위  → 은색 Bold (#9CA3AF)
3위  → 동색 Bold (#B45309)
나머지 → 기본 텍스트
```

#### 리더보드 테이블 행 애니메이션

판독 후 순위 변동 시 CSS transition으로 행 위치 이동 (300ms ease).
